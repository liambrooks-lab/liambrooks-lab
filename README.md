### 🔬 Active Research Repositories
Under the research wing of Voxion Labs, I lead the architecture and exploration of sandboxed runtime safety and multi-agent memory persistence. These efforts are materialized across three primary research engines:

*   **🛡️ [Aegis-IR](https://github.com/Voxion-Labs/Aegis-IR)**
    *   *System Focus:* Intermediate Representation & Compiler Security.
    *   *Abstract:* Aegis-IR is a robust intermediate representation compiler engine designed specifically for analyzing and sandboxing LLM-generated code. It acts as an isolation and security shielding layer, executing static code telemetry and validating safety parameters before code hits execution environments.
    *   *Primary Technologies:* C++, Abstract Syntax Trees (AST), Compilers.
*   **📦 [VXR-Sandbox](https://github.com/Voxion-Labs/VXR-Sandbox)**
    *   *System Focus:* Isolated Runtime Testing.
    *   *Abstract:* VXR-Sandbox is a high-security, deterministic execution environment built for running untrusted AI agent actions. It prevents execution leakage, supports isolated resource scaling, and provides real-time state telemetry to monitor anomalous execution patterns.
    *   *Primary Technologies:* Node.js, Web Workers, Docker API, System Call Monitoring.
*   **🌐 [VXR-Continuum](https://github.com/Voxion-Labs/VXR-Continuum)**
    *   *System Focus:* Stateful Multi-Agent Memory.
    *   *Abstract:* VXR-Continuum acts as a state-persistence backplane and low-latency memory routing network. It resolves the transient memory loss problem in distributed multi-agent workflows, ensuring that task execution history, system state, and context remain continuous across long-running pipelines.
    *   *Primary Technologies:* Python, Vector Databases, Key-Value State Stores.

## 💎 Core Engineering Projects
These are the foundational developer-grade products designed, built, and shipped under the **Voxion Labs** umbrella, representing our commitment to low-latency utility and robust backend design.

### 💻 [VoidLAB](https://github.com/liambrooks-lab/VoidLAB) — Minimalist Browser Cloud IDE
*VoidLAB is a zero-latency, sandbox-isolated browser IDE designed for seamless cross-platform developer workflows.*
*   **Core Architectural Features:** Supports isolated runtime execution loops, utilizes web worker background threads for non-blocking compilations, and features a responsive file explorer, dynamic tab system, and integrated web terminal.
*   **Primary Engineering Wins:** Achieved cross-device compatibility with zero state-leakage, ensuring standard developers can write and compile code directly from any mobile or desktop web browser.
*   **Tech Stack:** React, Next.js, TailwindCSS, Isolated Web Runtimes, Execution APIs.

### ⚙️ [FluxKernel](https://github.com/liambrooks-lab/FluxKernel) — Memory-Driven AI OS Agent
*FluxKernel serves as a persistent, memory-driven artificial intelligence agent that operates directly on standard filesystems.*
*   **Core Architectural Features:** Designed with a real-time terminal execution loop, self-correcting git-diff patching pipelines, and dynamic task routing between cloud LLMs and low-latency local models.
*   **Primary Engineering Wins:** Implemented a robust vector-based semantic memory backplane that persists state across execution sessions, allowing the agent to continuously build and maintain complex software repositories.
*   **Tech Stack:** Python, LangChain, Custom Vector Store, CLI Automation.

### 🌐 [HorizonSync](https://github.com/liambrooks-lab/HorizonSync) — Unified Collaborative Workspace
*HorizonSync is a high-performance productivity workspace enabling multi-user real-time state streaming.*
*   **Core Architectural Features:** Integrates dynamic file streaming, unified concurrent terminals, and shared workspace trees to allow multiple users and agents to pair-program simultaneously.
*   **Primary Engineering Wins:** Kept file synchronization latency under 15ms across concurrent sessions by optimizing diff payloads and web websocket data frames.
*   **Tech Stack:** TypeScript, Next.js, Node.js, Socket.io, Redis.

### 🔊 [LEXIO](https://github.com/Voxion-Labs/LEXIO) — Premium Text-To-Speech Web Engine
*LEXIO is a premium, real-time Text-To-Speech (TTS) engine focused on clean voice customization and document accessibility.*
*   **Core Architectural Features:** Powered by native browser Web Speech interfaces, LEXIO provides dynamic voice selection (male/female), adjustable regional accent modulations, and real-time sentence highlighting.
*   **Primary Engineering Wins:** Handled multi-format documents with low-latency segment parsing to guarantee seamless speech stream continuity without audio clipping.
*   **Tech Stack:** JavaScript, Web Speech API, CSS3 Grid/Flexbox layouts.

### 🎓 [SkillNODE](https://github.com/liambrooks-lab/SkillNODE) — Social Skill Acquisition Platform
*SkillNODE is a multi-page interactive platform combining rigorous programming practice, competitive coding rooms, and AI-driven study tracks.*
*   **Core Architectural Features:** Supports concurrent live coding rooms, user code performance analytics, and community developer lobbies.
*   **Primary Engineering Wins:** Created a real-time multiplayer coding arena where users can solve complex algorithm challenges in shared environments.
*   **Tech Stack:** Node.js, Express, Socket.io, React, MongoDB.
